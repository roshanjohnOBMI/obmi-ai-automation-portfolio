The show-stopper

OBMI Meridian.
The mother of all apps.

One command centre for every project. Meridian 2.0 opens on an Overview that says what needs attention first, then gives model sharing, issues, model performance, TIDP/MIDP, clash parameters, viewpoints and clashes a board each, so the BIM manager sees the whole portfolio without chasing anyone for a status.

  • Overview board with a status on every board, and a project switcher
  • Model sharing, issues and model performance, scored and trended
  • TIDP/MIDP progress and missing clash parameters, tracked report to report
  • Viewpoints and clash report, with a trade-against-trade matrix
  • Add-in Control: usage by office, versions, rollback and one switch
  • Excel and PDF exports on every board, in a light or dark theme
